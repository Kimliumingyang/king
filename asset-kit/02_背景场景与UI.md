# 背景 / 场景 / UI

## 三世界完整背景布置

每个世界交付 far / mid / foreground 三张独立 2560×1440 PNG（游戏逻辑视口 1280×720）。左右无缝平铺；采用相同地平线，别把可碰撞地形画进背景。远景可含天空底色，中景与前景透明。程序的真实草边与岩壁跟随物理路面；背景不参与碰撞。

最后 90–120 逻辑像素可放前景装饰；主操作区大约 y=300–560 留清楚。不要把 UI、角色、金币、断崖落点或王座烘焙到背景。原始概念图只作为风格参考。

## 地形 10 个分件

岩壁/草边、断崖标记、限高顶棚、跷跷板、移动平台、破桥单节、弹跳蘑菇、磁场发生器、风区飘带。岩壁和草边需要可平铺材质；实际弧形坡度由代码蒙版/地形描边处理。动态平台旋转/移动、桥断裂由真实刚体驱动，不能预先在素材里画一条更宽的安全着陆面。

## UI

Logo、纸质面板、酒红主按钮、奶油次按钮、禁用态、菜单/暂停/重开/声音开关/锁/星级/金币/五条升级图标、三键控制。按钮交付底图，不烘焙文字；面板请给九宫格内边距。所有文字仍由代码绘制，保留英文短句与触屏可点击面积。

背景与角色状态已有自动替换槽；音频按 cue ID 接入。UI 面板/Logo/按钮底图已有 CSS 槽。地形材质、特效、UI 图标上传后会逐项对齐当前碰撞轮廓与布局，不建议你为贴图修改物理参数。
