六事件的视觉/声音节奏：

- **hiccup / Royal Hiccup**：850ms “HIC...” 预警 → 短打嗝 → 杯子抖、皇冠松，轻角冲量。
- **sneeze / Royal Sneeze**：1200ms 鼻子蓄力 → “ACHOO!” → 纸巾飞走，轻水平冲量。
- **nap / Sudden Nap**：900ms 眼皮变沉 → “Zzz...” → 垂头/打鼾 2.3 秒，摩擦 ×0.92。
- **toast / Royal Toast**：900ms 举杯准备 → “CHEERS!” → 洒到自己披风，短轻微重心扭动；不移动刚体坐标。
- **scepter / Scepter Wave**：1200ms 权杖抬起 → “MAKE WAY!” → 士兵慌张，轻角冲量。
- **hurry / Royal Complaint**：750ms 张嘴 → “FASTER, PEASANTS!” → 纯对话；绝不自动加速 UFO。

动画请区分“蓄力预警”和“事件发动”。本版程序在断崖 1.5 秒缓冲、检查点、停靠区、救援保护期禁用危险事件；没有素材时用 SVG + 程序动效占位。王冠先掉是可见的风险反馈，丢皇冠本身不判输、不扣币。
