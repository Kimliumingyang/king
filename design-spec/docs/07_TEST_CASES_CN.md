# 07｜可执行验收场景与边界条件

> 测试状态：未运行。此清单用于 Codex 实现后逐项验证。

## P0：卡死/复活/存档
- T01 首次启动：3 秒内主菜单响应，首次开始 10 秒内可实际操作（目标，不含极端网络）。
- T02 国王落地→危险倒计时→失败菜单，显示 Royal Rescue/Retry Checkpoint/Restart Level。
- T03 Royal Rescue 后 2.5 秒保护、国王安全返回真实甲板，第二次死亡该 run 不再出现免费按钮。
- T04 复活刚开始强制刷新，不能恢复原来的免费次数。
- T05 进入 checkpoint 后失败，重生点无穿模，物理速度 0，已用救援状态保持。
- T06 checkpoint 前重复拿金币，前进再死亡反复 20 次，钱包不增长、不重复领取。
- T07 无广告、广告 blocked、SDK 初始化失败、广告未完成：检查点免费继续永远可用。
- T08 浏览器切后台 30s 再回来，无异常位移、无吞帧、无死亡事故。
- T09 移动端手指移出控制区域，推进按钮能可靠松开。
- T10 结算过程刷新，结算奖励幂等，下一关解锁不丢失。

## P1：物理与关卡
- T11 首关 30s 直行，国王不无故飞出；急刹与过度悬浮能导致可预测的滑落。
- T12 15 关默认能力下至少一份正常通关记录，有录像/逐帧 trace。
- T13 关卡 07、08、10、15 的移动平台、磁波都具有明显预警和安全窗口。
- T14 终点高速经过不胜利；速度低于 30px/s、倾角<=9°、国王安全 1.5 秒才通过。
- T15 在王座前丢国王，必须判失败而不是结算成功。
- T16 随机事件在断崖/终点区域/复活保护期不触发危险作用。

- T18 静音正确，切换网页时音效暂停，游戏恢复不重复播放背景音。
