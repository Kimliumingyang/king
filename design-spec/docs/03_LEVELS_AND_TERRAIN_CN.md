# 03｜15 关设计、复杂地形与物理喜剧

## 设计原则
1. **路径必须可达**：常规配置、零升级、无广告、单关至少能够不靠复活过关。开发阶段给出自动地形碰撞检测和 QA 调试跳转，而不是动态替玩家通关。
2. **挑战有节奏**：安全段（操作）→危险段（决策）→恢复段（奖励/检查点）→险段→终点停靠。首次出现的新机关单独教学；下一关组合；第三关检验。
3. **不以随机必死为笑点**：意外需要预警，物理随机种子可复现；相同初始条件应产生相同的主要结果。
4. **不依赖画面截图作为真实关卡**：参考图仅用于视觉，实际地形用碰撞线段、移动平台和脚本机关构成，全部数据驱动。

## 世界与尺度
- 基准 viewport 1280×720，摄像机跟随 UFO，游戏物理逻辑统一按每秒；横向关卡长度约 480–1800 世界像素，`distanceMeters=worldX / pixelsPerMeter`（默认 2.4px/m），展示的距离与计分按这个换算。
- 地形段长 140–460px；动态障碍必须带 `safeRecoveryZone`；检查点要预留至少 300px 平坦区域。
- 右侧画面留最少 35% 前瞻视野；高速时摄像机提前量增至 45%。UI 顶部、底部安全区不遮挡危险预警。
- 每关至少 2 种地形模板，第 4 关起至少 3 种；后期有 4 种以上模板的**组合**，而不是只换背景。

## 3 个世界主题
- **Royal Foothills / 皇家丘陵（L01–05）**：灰蓝天色、低饱和紫色蘑菇、黄绿地表；学习惯性、弹力、悬浮，不连续叠加超过 2 种高风险障碍。
- **Wobbly Wastes / 摇摆荒原（L06–10）**：粉灰沙丘、废旧悬浮设施、低饱和青色磁场；挑战间歇平台、磁波、持续滑动和限高。
- **Moonlit Citadel / 月光堡垒（L11–15）**：远景石桥、悬空城堡、月亮和低饱和夜蓝；多机制串联、精确停靠、合理重复挑战。

## 地形生成与防无解
- 15 个主线关的 `terrainSequence` 明确配置，障碍位置必须人工验收。V1 不做完全不可控的无限随机地形。
- 以固定 seed 实例化动态机关，支持关卡重试重置；所有落点使用 raycast 检查空间净高、降落速度、前后静态碰撞情况。
- `gap_jump` 限制缺口宽度（初始 <= UFO 默认 Boost 可跨距离的 70%）；`low_ceiling` 留出最低可通行净高；`moving_platform` 最少每 4s 有一个安全对接窗口；`crosswind` 只能小于稳定器可应对的力。
- 危险连招之间留 ≥220px 恢复段（后期允许 ≥160px）；检查点保护区不得出现随机重大干扰。
- 禁止碰撞体与可视地面错位超过 5px；用 debug overlay 显示碰撞面、重生点、危险窗口。

## 物理喜剧如何与地形联动
- 悬浮蘑菇：国王被轻微弹起，落回 UFO 时王冠晚 0.3 秒落下。
- 限高隧道：国王惊恐低头（可通过动画），但不能强制穿模；飞船撞顶应可预期。
- 跷跷板：两个士兵朝两端踉跄，一人伸手救皇冠，视觉层附着船体不影响真实质量。
- 桥梁：塌桥后飞船临时失去左探针支撑，玩家 Boost 可过；破桥不能提前消失。
- 磁暴：飞碟引擎咳嗽、冒出卡通“?”，降落力度随机幅度受严格上限控制。
- 成功停靠：国王想跳到王座但笨重地小滑一下（结算后表演，不影响胜利判定）。

## 分关卡测试
每关至少三组模拟/真人 QA：零升级+零救援、基础升级+一次救援、最大允许升级；全部可达并无卡死。对移动平台、跳崖、加载游戏和改尺寸逐项记录失效位置。实际时长来自测试后调整 `timeGoldSec` 与 `timeSilverSec`，不得仅凭设计值宣称通过平台审核。
