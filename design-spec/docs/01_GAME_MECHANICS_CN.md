# 01｜完整游戏机制（GDD v1.1）

## A. 玩法一句话
两名倒霉外星骑兵操纵一艘二手磁悬浮飞碟，载着好吃懒做、容易滚落的外星国王，穿越充满荒谬物理障碍的中世纪外星王国，将国王安全送回每关的王座。**玩家失败的方式必须滑稽、可理解、可改进**。

## B. 游戏目标与定位
- 标题：Don't Drop the King! / 别把国王摔了！
- 类型：横版 2D 物理平衡 / 技巧闯关 / 轻量成长 / Slapstick Comedy。
- 平台：Web HTML5，桌面和手机横屏，目标 16:9 安全区域；适配从 1280×720 到 1920×1080 的 viewport，超宽屏优先扩展背景不影响操作视野。
- 每关目标：**安全运送至终点 Royal Throne 的停靠区并停稳 1.5 秒**，国王未跌落，飞碟角度和速度均低于阈值。
- 单关第一次成功约 1–3 分钟；15 关 + 失败重试预计 30–60 分钟首次体验（推测，须数据验证）。主线外提供三星、高分和每日挑战。
- 全部游戏不需要文字剧情；英文文案简短直白，配合表情。

## C. 操作：三键即可上手
- D / →：向右推进；A / ←：刹车、减速、反向推进。触屏左右两个大按钮。松开时惯性减速。
- Space / W：**Hover Boost**：按住提升目标悬浮高度、帮助飞越断裂处；消耗能量，松开缓慢恢复。触屏右下第三按钮。
- 方向不直接控制“人物位置”，而是控制动力/加速度。飞艇因为坡面和加速度产生前后俯仰，国王依靠摩擦留在其上；优秀操作是慢进险坡、合理制动、短喷越坑。
- P / Esc：暂停；R：重置关卡（必须二次确认防误触）；M：静音。
- 可选进阶模式：Q/E = 微调俯仰 ±力矩（关卡 7 以后引导，默认隐藏）。**首版不强制引入，先验证三键深度**。
- 游戏默认自动在背景页面暂停；广告播放必须暂停物理与音频。

## D. 5 个主要交互感
1. **速度惯性**：冲刺时能上陡坡，但突然刹车会使国王向前滑。
2. **悬浮支撑**：飞艇正常距地有高度；低洼会下降，台阶与磁场影响浮力；船体能倾斜但受限于自动稳定。
3. **独立国王**：国王与船体通过刚体碰撞接触，自行滑动、转动；大肚子上有明显圆形重心。出界才真的失败。
4. **善意预警**：危险倾角、国王靠近边缘、特殊事件到来，会以表情/音效/UI 提示（不依赖中文文字）。
5. **幽默反馈**：颠簸时酒杯洒、皇冠歪、骑兵流汗，失败时国王进入可控观赏的短暂布娃娃飞行和搞笑台词。

## E. 胜利 / 失败 / 结算
胜利同时满足：
- 飞碟中心进入指定 `dockZone`，与王座同屏，距离目标 <= `dockRadiusPx`；
- 速度模长 <= `dockMaxSpeedPxS`，角度绝对值 <= `dockMaxAngleDeg`，持续 `dockHoldMs`；
- 国王仍接触飞碟承载面，未处于跌落/失控状态。
- 到达终点前需要主动减速；不能简单以 x>finishX 判胜。
失败条件：
- 国王离开甲板且超过可救回边界 0.65 秒；
- 国王落入地图死亡区域、飞船被强障碍毁坏、超出安全地图；
- 失败前 0.4–0.7 秒可进入 `DANGER`（边缘晃动、警报）。如果国王安全回到甲板就取消。
失败动画：1–2 秒短演出后进入 `FAIL_MENU`，所有场景逻辑停住，不妨碍一键重试。
- 国王被抛飞时不强制回收硬币、不要引入死亡折磨动画。

## F. 关卡系统
- 15 个手工配置关卡（配置在 data/levels.json），3 个主题：Royal Foothills (1–5)，Wobbly Wastes (6–10)，Moonlit Citadel (11–15)。地形模块可复用，但**核心危险组合应经人工可达性测试**，不纯依赖无限程序生成。
- 每关默认 2 个检查点，Level 1 可只设 1 个；新危险元素首次单独介绍，二次组合，三次考试。
- 从关卡 3 开始引入两段及以上多障碍组合，后期至少包含“动平台+乱流”、“坡道+反重力”、“跷跷板+限高”等。
- 失败时有清楚的重试目标，不靠无限拖慢或强制看广告延长游玩。

## G. 星级系统
- 1 星：成功护送抵达。
- 2 星：达到该关设定的 `timeSilverSec` 且不使用超过 1 次救援。
- 3 星：达到 `timeGoldSec`，没有任何救援且国王没有严重滑落（`dangerCount <= 2`）。
- 初次过关即解锁下一关，不用三星卡关。最佳成绩永久保存。
- 收集币用于升级，三星用于可选外观/搞笑台词解锁，不强制刷星购买主线进度。

## H. 任务与回访
- 普通任务：累计完成 5 个关卡、10 次成功停靠、累计 5,000m、险些摔落后恢复 3 次、获得 3 个三星等。
- 每日挑战：用已有关卡种子增加一条特定规则（例如 Boost 较弱 / 地形反弹更大 / 无救援加分），每天提供一次基础奖励。无需联网时可本地每日重置；平台数据可用则走平台能力。
- 记录：最佳用时、最远飞行距离、国王最长摔落翻滚距离（搞笑统计，不支付奖励）、总计丢掉的皇冠数。
- 角色与飞碟外观：可选，不影响物理真实特性，后续版本更新。

## I. 搞笑事件规则
详见 `data/king_events.json`，包括：打嗝、喷嚏、打盹、举杯干杯、挥权杖、放话催促。
- **危险事件必须预警**（视觉 0.6–1.2 秒，音效可静音）。
- 在断崖 1.5 秒内、终点停靠区和复活保护期不得随机触发会导致重大失控的事件。
- 同一关连续两次失败，关卡中的首次随机危险事件应降级为温和版（隐藏的无障碍辅助，不改变关卡完成要求）。
- 每个事件要有触发概率上限、间隔冷却和可复现随机种子；玩家不能被纯随机致死。

## J. HUD 与画面
- 左上：菜单、游戏 logo。中上：LEVEL XX、飞碟到王座进度条、检查点。右上：距离 / 关卡长度、静音、重开。
- 操作区域不遮挡地形和飞碟；小屏上可折叠 HUD。金币不必游戏中实时占过多空间，可在结算显示。
- 画风以 `reference/APPROVED_GAMEPLAY_STYLE.png` 为唯一基准：低饱和灰蓝、灰紫、奶油白、酒红、少量青色悬浮光；深描边、简笔但富有表情；保留幽默但不恶心。
- 飞碟内部仅简易窄平台，**不要形成深沙发护栏**；国王能真实滑出，甲板宽度与人物尺寸需要调到有风险但不至于只走 10 秒就落下。

## K. 第一次进入游戏体验
0–5 秒：标题页 `PLAY`，进入 Level 01，默认无需阅读教程。
5–15 秒：按 D 右行，通过短平坡，显示“Hold D to move”。
15–35 秒：出现缓坡、提示“Slow down”，触发轻微晃动、第一次临近滑落但可以补救。
35–55 秒：抵达第一个自动检查点 + 安全平台。
55–90 秒：简短起伏 + 一次低风险幽默事件，学习悬浮增强。
90–120 秒：终点停稳，第一次通关获得金币，弹出 `NEXT` 与 `UPGRADE` 入口。

## L. 不做什么
- 不做 3D、真实多人联机、复杂对话、长教程、强制手机号登录。
- 不做随机物理死亡、必看广告才能继续、不做无限复活刷钱漏洞。
- MVP 不做 20 种付费皮肤、虚假排行榜和无法完成的每日任务。
